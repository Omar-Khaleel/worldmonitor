# عين الصقر — وضع محطة البث

يضيف هذا الفرع وضعين منفصلين إلى لوحة المعلومات:

- **غرفة التحكم:** اختيار الخريطة، الشاشات، عدد الأعمدة، الشريط الإخباري، وسيلة الترجمة، ثم إنشاء رابط بث.
- **شاشة المشاهد:** تعرض فقط الخريطة والشاشات المختارة وشعار «عين الصقر» وشريط الأخبار السفلي، من دون إعدادات أو رؤوس لوحات أو روابط خارجية.

## التشغيل المحلي

```bash
git checkout broadcast-station-mvp
npm install
npm run dev -- --host 0.0.0.0
```

غرفة التحكم:

```text
http://localhost:3000/control
```

قالب المشاهد الافتراضي الجاهز:

```text
http://localhost:3000/broadcast
```

عند فتح `/broadcast` من دون إعداد `bcfg`، ينشئ النظام تلقائياً قالباً رسمياً يحتوي على:

- الخريطة العالمية.
- لوحات التحليل الاستراتيجي والاستخبارات والمخاطر المتاحة.
- ثلاثة أعمدة من دون مسافات بينية.
- شعار «عين الصقر» وعلامة البث المباشر.
- شريط أخبار عربي عالمي وسياسي مفعّل تلقائياً.

أما رابط المشاهد الناتج من غرفة التحكم، فيحمل خيارات المستخدم داخل `bcfg` ويتقدم على القالب الافتراضي.

من غرفة التحكم:

1. اختر الشاشات المطلوبة.
2. اختر عدد الأعمدة وإظهار الخريطة.
3. فعّل الشريط الإخباري والترجمة.
4. اضغط **حفظ الإعدادات**.
5. اضغط **فتح شاشة المشاهد** أو **نسخ رابط البث**.

## الشريط الإخباري العالمي

الشريط لا يعتمد فقط على الخانات التي اختارها المستخدم للعرض. بل يجمع العناوين من جميع لوحات الأخبار التي حمّلها البرنامج، ويعطي أولوية إلى:

- الأخبار العالمية والسياسية.
- الأزمات والصراعات والأمن.
- الأخبار الإقليمية في أوروبا والشرق الأوسط وآسيا وأفريقيا والأمريكيتين.
- الاقتصاد والطاقة والأسواق والتقنية بوصفها مصادر ثانوية.

ثم يقوم النظام بما يأتي:

- إزالة الأخبار المكررة.
- ترتيب المصادر حسب الأولوية الإخبارية.
- ترجمة العناوين على دفعات إلى العربية.
- رفض عرض العنوان الإنجليزي في الشريط إذا تعذرت ترجمته.
- تخزين الترجمات مؤقتاً لتقليل الطلبات وتحسين الأداء.
- تحديث الشريط دورياً وعند وصول أخبار جديدة.

## شاشة مشاهد نظيفة

في وضع المشاهد تُخفى تلقائياً:

- أدوات الخريطة والطبقات والتقريب والتوقيت والفلاتر.
- أزرار الإعدادات والتبويبات ومبدلات القنوات.
- أسماء القنوات وأسماء الكاميرات والمدن والمواقع داخل لوحات البث المرئي.
- أزرار الكتم والتشغيل والملء الكامل والترجمة اليدوية.

إذا اختار مدير المحطة لوحة بث مباشر أو كاميرات، يحاول وضع المشاهد تشغيل الوسائط تلقائياً مع كتم الصوت وإخفاء عناصر التحكم.

## الاستخدام مع OBS

أضف **Browser Source** ثم ضع رابط البث الذي تنسخه غرفة التحكم.

إعدادات مقترحة:

```text
Width: 1920
Height: 1080
FPS: 30
Shutdown source when not visible: Off
Refresh browser when scene becomes active: On
```

رابط المشاهد يحمل الإعدادات داخله في المعامل `bcfg`، لذلك يمكن وضع الرابط نفسه على جهاز آخر أو لدى الزبون من دون نقل localStorage.

## الترجمة العربية

### 1. Ollama محلي

من غرفة التحكم اختر:

```text
مصدر الترجمة: Ollama محلي
عنوان Ollama: http://127.0.0.1:11434
النموذج: qwen2.5:7b
```

على Windows اسمح لأصل لوحة التحكم بالوصول إلى Ollama ثم أعد تشغيل Ollama:

```powershell
setx OLLAMA_ORIGINS "http://localhost:3000"
```

عند استخدام عنوان شبكة آخر، استبدل `localhost:3000` بعنوان الخادم الفعلي.

### 2. خادم ترجمة مركزي

واجهة المشاهد تستدعي:

```text
POST /api/broadcast/translate
```

والخادم يتصل بأي مزود متوافق مع OpenAI Chat Completions عبر متغيرات البيئة التالية:

```text
BROADCAST_TRANSLATION_BASE_URL=https://provider.example/v1
BROADCAST_TRANSLATION_API_KEY=secret
BROADCAST_TRANSLATION_MODEL=model-name
```

الشريط يستخدم سلسلة بدائل: الخادم المركزي، ثم Ollama، ثم خدمة الترجمة الموجودة داخل البرنامج. ولا يعرض في الشريط إلا نتيجة عربية.

## تصدير واستيراد إعداد المحطة

غرفة التحكم تدعم:

- تصدير ملف `ayn-al-saqr-broadcast.json`.
- استيراد ملف إعداد سابق.
- نسخ رابط بث يحمل التكوين نفسه.

## حدود النسخة الحالية

- اختيار الشاشات والتخطيط يعمل من داخل نفس نسخة المشروع.
- رابط البث مناسب لجهاز مشاهد آخر أو OBS Browser Source.
- النشر المركزي لعدة زبائن بأسماء profiles محفوظة في قاعدة بيانات لم يُضف بعد؛ يمكن إضافته عبر API وقاعدة بيانات.
- جودة الترجمة وسرعتها تعتمد على توفر مزود الترجمة المختار واتصال الشبكة.
