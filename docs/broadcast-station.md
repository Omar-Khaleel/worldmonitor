# عين الصقر — محطة البث والتحكم المباشر

يضيف هذا الفرع وضعين منفصلين إلى لوحة المعلومات:

- **غرفة التحكم:** إدارة الشاشات، القنوات، كاميرات الويب، طبقات الخريطة، مصادر البيانات، التخطيط، الشريط والترجمة.
- **شاشة المشاهد:** تعرض فقط المخرجات التي يحددها مدير المحطة، مع شعار «عين الصقر» وشريط أخبار عربي، من دون أدوات تحرير أو إعدادات.

## التشغيل المحلي

```bash
git checkout broadcast-station-mvp
npm install
npm run dev -- --host 0.0.0.0
```

غرفة التحكم:

```text
http://localhost:3000/control
```

شاشة المشاهد الافتراضية:

```text
http://localhost:3000/broadcast
```

داخل غرفة التحكم يظهر **رابط حي ثابت للمحطة** بالشكل الآتي:

```text
http://localhost:3000/broadcast?station=ayn-xxxxxxxxxxxx&lang=ar
```

استخدم هذا الرابط في شاشة المشاهد أو في OBS. لا يحتاج الرابط إلى إعادة النسخ عند كل تعديل.

## المزامنة الفورية

كل تعديل في غرفة التحكم يُنشر تلقائياً بعد فترة قصيرة جداً، من دون الضغط على حفظ ومن دون تحديث صفحة المشاهد.

تستخدم المزامنة ثلاث وسائل:

1. `BroadcastChannel` للتحديث الفوري بين تبويبات المتصفح نفسه.
2. حدث التخزين المحلي كوسيلة احتياطية بين التبويبات.
3. `GET/PUT /api/broadcast/state` للمزامنة بين الأجهزة باستخدام رقم المحطة الموجود في الرابط، مع فحص كل ثانية.

زر **حفظ الإعدادات** أصبح أيضاً زر نشر يدوي فوري، بينما **نسخ رابط البث** ينسخ الرابط الثابت الحي وليس رابطاً جديداً يحمل الإعدادات داخله.

> عند تشغيل Vite محلياً من دون طبقة API، تعمل المزامنة الفورية بين تبويبات المتصفح نفسه. المزامنة بين أجهزة مختلفة تتطلب تشغيل/نشر مسار `api/broadcast/state.ts` على الخادم نفسه. التخزين الحالي داخل نقطة API مناسب للتجربة وخادم Node واحد؛ النشر الإنتاجي متعدد النسخ يحتاج مخزناً دائماً مثل Redis أو Convex.

## التحكم الكامل من غرفة التحكم

### الشاشات ومصادر API

القائمة الأصلية لجميع لوحات البرنامج بقيت متاحة، مع:

- بحث فوري بالاسم أو المعرّف.
- تصنيف الأخبار العالمية والإقليمية.
- تصنيف التحليل والاستخبارات.
- تصنيف الاقتصاد والأسواق والطاقة.
- تصنيف الأمن والدفاع.
- قسم لبقية البيانات وواجهات API.

إلغاء اختيار أي شاشة يخفيها فوراً من المشاهد، واختيارها يعيدها من دون تحديث الصفحة.

### القنوات المباشرة

غرفة التحكم تعرض قائمة قابلة للبحث لجميع القنوات المتوفرة في المشروع، مثل القنوات العربية والعالمية. يمكن اختيار عدة قنوات في وقت واحد، وتظهر في المشاهد داخل **جدار بث** نظيف ومكتوم الصوت.

### كاميرات الويب

يمكن اختيار عدة كاميرات ومشاهد مباشرة، منها الشرق الأوسط وأوروبا والأمريكيتان وآسيا والفضاء. تظهر المصادر المختارة فقط داخل جدار البث.

### طبقات الخريطة

يمكن التحكم بطبقات الخريطة ومصادرها، مثل:

- الصراعات والنقاط الساخنة.
- النشاط العسكري والعقوبات.
- الطقس والكوارث الطبيعية.
- الطيران والسفن والممرات المائية.
- المنشآت النووية والإشعاع.
- الحرائق والاحتجاجات والانقطاعات.
- التهديدات السيبرانية ومراكز البيانات.

تُحفظ حالة الطبقات وتُطبّق في المشاهد، بينما تبقى أدوات التحكم نفسها مخفية عنه.

## قالب المشاهد الافتراضي

عند فتح `/broadcast` للمرة الأولى، ينشئ النظام تلقائياً قالباً يحتوي على:

- الخريطة العالمية.
- لوحات التحليل الاستراتيجي والاستخبارات والمخاطر المتاحة.
- ثلاثة أعمدة من دون مسافات بينية.
- شعار «عين الصقر» وعلامة البث المباشر.
- شريط أخبار عربي.
- قنوات عربية وكاميرات مختارة كإعداد ابتدائي لجدار البث.

## الشريط الإخباري العربي

الشريط لا يعتمد على الخانات المرئية فقط. بل يجمع العناوين من جميع لوحات الأخبار المحملة في البرنامج، بما فيها اللوحات المخفية عن المشاهد، ويعطي أولوية إلى:

- الأخبار العالمية والسياسية والحكومية.
- الأزمات والصراعات والأمن والعقوبات.
- الأخبار الإقليمية في أوروبا والشرق الأوسط وآسيا وأفريقيا والأمريكيتين.
- الاقتصاد والطاقة والأسواق والتقنية.

ثم يقوم بما يأتي:

- إزالة الأخبار المكررة.
- ترتيب الأخبار حسب الأولوية.
- عرض الأخبار العربية المتوفرة فوراً.
- ترجمة الأخبار الإنجليزية على دفعات.
- تخزين الترجمة مؤقتاً لمدة محدودة.
- إعادة الفحص بعد بدء التشغيل وعند وصول بيانات جديدة وكل 30 ثانية.
- عرض حالة عربية واضحة أثناء انتظار الأخبار أو عند تعذر الترجمة بدلاً من ترك الشريط فارغاً.

سلسلة الترجمة هي:

1. Ollama المحلي أو خدمة البرنامج، حسب إعداد غرفة التحكم.
2. خدمة الترجمة الموجودة داخل البرنامج.
3. خادم الترجمة المركزي بوصفه خياراً احتياطياً.

## شاشة مشاهد نظيفة

في وضع المشاهد تُخفى تلقائياً:

- إضافة لوحة أو إضافة خانة أو إضافة Widget.
- مواضع اللوحات الفارغة ومقابض تغيير الحجم.
- أدوات الخريطة والطبقات والتقريب والتوقيت والفلاتر.
- أزرار الإعدادات والتبويبات ومبدلات القنوات.
- أسماء القنوات والكاميرات والمدن والمواقع التي تضيفها واجهة البرنامج.
- أزرار الكتم والتشغيل والملء الكامل والترجمة اليدوية.
- رؤوس اللوحات والفواصل الإدارية التي لا يحتاجها المشاهد.

جدار البث المخصص يعرض الفيديو أو البث نفسه فقط، ويعيد بناء نفسه مباشرة عند تغيير القنوات أو الكاميرات من غرفة التحكم.

## الاستخدام مع OBS

أضف **Browser Source** ثم ضع الرابط الحي الذي يظهر في غرفة التحكم.

```text
Width: 1920
Height: 1080
FPS: 30
Shutdown source when not visible: Off
Refresh browser when scene becomes active: Off
```

اجعل خيار إعادة تحميل المتصفح عند تفعيل المشهد غير مفعّل، لأن الصفحة تتلقى الإعدادات مباشرة ولا تحتاج إلى إعادة تحميل.

## الترجمة عبر Ollama

من غرفة التحكم اختر:

```text
مصدر الترجمة: Ollama محلي
عنوان Ollama: http://127.0.0.1:11434
النموذج: qwen2.5:7b
```

على Windows:

```powershell
setx OLLAMA_ORIGINS "http://localhost:3000"
ollama pull qwen2.5:7b
taskkill /F /IM ollama.exe
ollama serve
```

عند فتح البرنامج بعنوان شبكة مختلف، أضف أصل ذلك العنوان إلى `OLLAMA_ORIGINS` بدلاً من `localhost:3000`.

## خادم الترجمة المركزي

واجهة المشاهد تستدعي:

```text
POST /api/broadcast/translate
```

ويمكن ربطها بمزود متوافق مع OpenAI Chat Completions:

```text
BROADCAST_TRANSLATION_BASE_URL=https://provider.example/v1
BROADCAST_TRANSLATION_API_KEY=secret
BROADCAST_TRANSLATION_MODEL=model-name
```
